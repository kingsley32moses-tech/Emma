# UI redesign notes

This update refreshes the public website and admin workspace with a cohesive forest-green, warm-neutral and restrained champagne palette. It improves typography, spacing, card treatments, hero composition, portfolio presentation, forms, responsive navigation, dashboard surfaces, tables, and login styling.

The redesign preserves the existing Node/Express routes, forms, admin JavaScript, database behavior, and content management features. Public hero/portfolio imagery currently uses remote Unsplash image URLs as visual placeholders; replace these with Emma's approved event photography before launch. Google Fonts and these placeholder images require an internet connection.

No backend or authentication behavior was intentionally changed in this visual update.
