# Emma's Decor Mw — design refresh

This update applies a consistent forest-green, champagne-gold and warm-ivory visual system across:
- Public homepage (existing luxury layout retained and refined)
- Event Designer (guided form, material catalogue and MWK estimate layout)
- Admin login/dashboard (matching brand palette and responsive navigation)
- Customer portal (matching palette and mobile refinements)

The existing Express routes, authentication, planner API, database schema and catalogue logic are preserved.

Important:
- This is a front-end styling refresh; it does not create real supplier records or verify supplier prices.
- The planner only totals catalogue entries with fixed prices already entered by an administrator.
- Test the customer/admin login and planner on the deployed service after uploading this ZIP.
