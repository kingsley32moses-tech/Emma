# Emma's Decor MW — foundation milestone

This repository starts the from-scratch implementation of the Emma's Decor MW platform.

## Included in this milestone
- React + TypeScript + Vite foundation
- Responsive public-facing landing page
- Initial forest / champagne / ivory design system
- Editorial typography and atmospheric CSS motion
- Mobile navigation
- Public sections: About, Services, Gallery, How it works, Contact
- Account-access preview modal that clearly states authentication is not implemented yet
- Reduced-motion support

## Important content notes
- Service examples are provisional and must be confirmed by the business before publication.
- Gallery visuals are CSS design placeholders, not photographs of real Emma's Decor MW projects.
- No phone number, WhatsApp number, address, social account, testimonial, price or business achievement has been invented.
- Login and registration are not connected to a backend in this milestone.

## Run locally
Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
